# GridGuard AI

## Household Energy Theft Detection using AI + GNN

GridGuard AI is an intelligent energy monitoring system designed to
identify suspicious household electricity consumption patterns using:

- Machine Learning
- Anomaly Detection
- Graph Neural Networks
- Explainable AI
- Generative AI
- Dynamic monitoring
